How to interpret

This tool does not scrape AI platforms or extract entities from natural language. It needs user-supplied structured annotations. The demo is fictional and is not the published Telescop dataset.

Each row represents one query × one run × one surface. Entries in the mentions, recommendations and citations columns use | to separate values. Entity counts are case-insensitive exact labels counted once per observation.
