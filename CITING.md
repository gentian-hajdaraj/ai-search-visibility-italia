# How to cite this research

## Preferred citation — frozen v1.0 dataset

```text
Gentian Hajdaraj. (2026).
AI Search Visibility in Italia — Dataset e metodologia v1.0
(Version v1.0) [Dataset].
Zenodo.
https://doi.org/10.5281/zenodo.22640375
```

## Web report

```text
Hajdaraj, Gentian. 2026.
AI Search Visibility in Italia: Brand e fonti nelle risposte di ChatGPT,
Gemini e Google AI.
Telescop Research.
Published 5 September 2026; revised 9 September 2026.
https://telescop.it/research/ai-search-visibility-italia/
```

## Which identifier should I use?

Use the **version DOI** `10.5281/zenodo.22640375` when citing the frozen v1.0 release.

The GitHub repository is intended for discovery, documentation and versioned companion materials. It should not replace the DOI as the primary archival identifier.

## Reporting a number

When citing a specific value from the study, preserve at least:

- metric/value;
- AI surface;
- observation period;
- denominator/base;
- dataset/methodology version.

This avoids turning a surface-specific result into a universal claim.
