# Contributing

This repository documents a frozen research release. Contributions are welcome when they improve clarity, reproducibility or error reporting without silently changing the published dataset.

## Appropriate contributions

- documentation corrections;
- broken-link fixes;
- reproducibility notes;
- clarification requests;
- confirmed data/documentation inconsistencies;
- proposals for future study versions.

## Frozen-release rule

The v1.0 dataset identified by DOI `10.5281/zenodo.22640375` must not be silently rewritten.

Any change that alters the research data, panel, classification rules or published metrics should be released as a new documented version with updated provenance.

## Reporting an issue

Please include:

- file/section;
- expected behavior or value;
- observed behavior or value;
- supporting evidence;
- research version and, where relevant, AI surface.
